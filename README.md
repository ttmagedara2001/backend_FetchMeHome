# Fetch Me Home – Backend 🐾

**Fetch Me Home** is a web-based pet adoption platform that aims to bridge the gap between homeless animals and loving families. This backend system provides all the core functionalities required to manage pets, users, and adoption requests in a secure, efficient, and scalable way.

Built using **Java Spring Boot**, secured with **JWT**, and powered by **MongoDB**, this API is designed to support a full-stack application with both user-facing and administrative interfaces.

---

## 🛠️ Tech Stack

- **Backend Framework**: Java + Spring Boot
- **Authentication**: JWT (JSON Web Tokens)
- **Database**: MongoDB (NoSQL)
- **Other Tools**: Spring Security, Spring Data MongoDB

---

## ✨ Key Features

- 🔐 Secure user registration and login system
- 🐶 Pet management (create, view, update, delete)
- 📝 Adoption request handling and tracking
- 👤 Role-based access control for admins and users
- 📦 RESTful API architecture
- 🔍 Easily integrable with frontend systems (React, Angular, etc.)
